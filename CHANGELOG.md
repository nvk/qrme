# Changelog

## 0.2.0 - 2026-09-15

- Adds a `Read QR Code` service for selected image data and image files.
- Adds an `Open QR Code…` command to the regular app.
- Shows decoded contents locally with copy and explicit HTTP/HTTPS link actions.

## 0.1.0 - 2026-05-07

- Initial public release.
- Adds a macOS Services-menu bundle that turns selected text into a QR code.
- Includes an offline Swift QR renderer, install/uninstall scripts, and a release packaging script.
